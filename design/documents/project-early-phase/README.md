## project-early-phase 说明（ai-agent-dev-system）

本目录用于承载 `ai-agent-dev-system` 仓库自身在「项目前期 / 治理体系演进」阶段的变更文档与记录，例如：

- 多 Agent 方案 V2.1 / V2.2 的设计与落地；  
- 治理内核与宿主适配层（platform-adapters/*）的初始化与重构；  
- 针对本仓库自身的规则调整与结构梳理。

当前这轮工作（多 Agent 方案 V2.2 第一批落地：`platform-adapters/`、根 `AGENTS.md`、`.cursor/rules` 瘦身、README 与主 Agent 文档改写）暂归属于 `project-early-phase`，后续如需为某次大版本演进创建独立 change-id，可在新的 `[change-id]` 目录下补充更细化的需求与验收文档。
